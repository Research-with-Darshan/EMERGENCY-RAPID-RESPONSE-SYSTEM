# Original coursework datasets

Place  the five original files supplied by the coursework team in this folder:

-  incidents.json
- responders.json
-  intelligence.json
- dispatch.json
-  audit.json

The original files  should be copied  here unchanged. They  were not present in the materials uploaded for this build, so no replacement or  fabricated records have been created.

The classification API reads  each file only when it exists and  is valid JSON. It produces operational, analytics and  research views in the response;  it does not overwrite the source.
